# Lessons Learned — mejoras al workflow

> Cada vez que descubras algo que mejore el proceso (un skill ineficiente, un campo faltante en una plantilla, una etapa que se podía simplificar), regístralo aquí con fecha. Cuando aplica, también actualizamos el skill/plantilla correspondiente.

> Formato: fecha → contexto → cambio → impacto.

---

## 2026-05-15 — Setup inicial del workflow

**Contexto:** Creación de la plantilla y skills basados en PRISMA 2020.

**Cambios:**
- 9 skills definidos (6 core + 3 admin)
- 10 MCPs configurados (biomcp, zotero, openalex, github, etc.)
- Estructura `_template/` + `projects/` + `docs/`
- `STATUS.md` como panel de control de cada proyecto

**Impacto:** Tiempo estimado por meta-análisis sin workflow: ~6 meses. Con este workflow: 2-3 meses.
